### 1. EMA Gravity Removal Attenuation (`emaAlpha = 0.1f` at $f_s = 100\text{ Hz}$)
- **Source Code Locations:**
  - Kotlin: [`WelchPsdEngine.removeGravityAndDetrend`](file:///data/data/com.termux/files/home/play-ground/ronin_shm/core/dsp/src/main/kotlin/com/ronin/phoneshm/core/dsp/WelchPsdEngine.kt#L268-L321) (`val alpha = parameters.emaAlpha` where `emaAlpha: Float = 0.1f` at line 28)
  - C++20: [`removeGravityAndDetrend`](file:///data/data/com.termux/files/home/play-ground/ronin_shm/core/dsp/src/main/cpp/dsp_core.cpp#L22-L79) (`float emaAlpha = 0.1f` default in [`dsp_core.h:76`](file:///data/data/com.termux/files/home/play-ground/ronin_shm/core/dsp/src/main/cpp/dsp_core.h#L76))
- **Mathematical Derivation:**
  - Gravity estimation recurrence:
    $$g[n] = \alpha x[n] + (1 - \alpha) g[n-1], \quad \alpha = 0.1$$
  - Subtracting $g[n]$ from $x[n]$ yields the high-pass residual $y_{\text{EMA}}[n] = x[n] - g[n]$ with $z$-transform transfer function:
    $$H_{\text{EMA}}(z) = 1 - \frac{\alpha}{1 - (1-\alpha)z^{-1}} = \frac{(1-\alpha)(1 - z^{-1})}{1 - (1-\alpha)z^{-1}}$$
  - Evaluating on the unit circle $z = e^{j\omega}$ where $\omega = 2\pi f / f_s$ ($f_s = 100\text{ Hz}$, $1-\alpha = 0.9$):
    $$|H_{\text{EMA}}(e^{j\omega})| = \frac{(1-\alpha)\sqrt{2 - 2\cos\omega}}{\sqrt{1 + (1-\alpha)^2 - 2(1-\alpha)\cos\omega}} = \frac{0.9\sqrt{2 - 2\cos(2\pi f / 100)}}{\sqrt{1.81 - 1.8\cos(2\pi f / 100)}}$$
  - Solving $|H_{\text{EMA}}(e^{j\omega_c})|^2 = \frac{1}{2}$ ($-3\text{ dB}$ cutoff):
    $$\cos\omega_c = 1 - \frac{\alpha^2}{2(1-\alpha)^2} = 1 - \frac{0.01}{1.62} = 0.993827 \implies f_c = \frac{100}{2\pi}\arccos(0.993827) = \mathbf{1.6763\text{ Hz}} \quad \left(\approx -\frac{f_s \ln(1-\alpha)}{2\pi} = 1.6769\text{ Hz}\right)$$
  - Next, [`highPassFilter`](file:///data/data/com.termux/files/home/play-ground/ronin_shm/core/dsp/src/main/kotlin/com/ronin/phoneshm/core/dsp/WelchPsdEngine.kt#L397-L445) applies a 2nd-order Butterworth forward-backward (`filtfilt`) filter at $f_{\text{HPF}} = 0.5\text{ Hz}$ with zero-phase squared magnitude response:
    $$|H_{\text{HPF}}(f)| = \frac{1}{1 + (0.5 / f)^4}$$
  - **Combined Theoretical vs. Measured Signal Retention ($f_s = 100\text{ Hz}$):**

| Frequency $f_0$ | $|H_{\text{EMA}}(f_0)|$ (Theory) | $|H_{\text{EMA}}(f_0)|$ (Measured) | $|H_{\text{HPF}}(f_0)|$ (Theory) | Total Amp Gain $|H_{\text{total}}|$ (Theory / Meas) | Total Power Gain $|H_{\text{total}}|^2$ | Power Loss (%) |

### 3. Magnitude PSD Inconsistency (`psdX + psdY + psdZ` vs. Welch PSD of $\sqrt{x^2+y^2+z^2}$)
- **Source Code Locations:**
  - Kotlin: [`WelchPsdEngine.kt:554-563`](file:///data/data/com.termux/files/home/play-ground/ronin_shm/core/dsp/src/main/kotlin/com/ronin/phoneshm/core/dsp/WelchPsdEngine.kt#L554-L563) computes `magPsdValues[i] = psdX.psdValues[i] + psdY.psdValues[i] + psdZ.psdValues[i]` (Total Vector Power / Trace of the $3\times 3$ spectral matrix $\text{Tr}(\mathbf{G}(f)) = S_{xx}(f) + S_{yy}(f) + S_{zz}(f)$).
  - C++20: [`dsp_core.cpp:546-562`](file:///data/data/com.termux/files/home/play-ground/ronin_shm/core/dsp/src/main/cpp/dsp_core.cpp#L546-L562) computes `rawMag = fuseAxes(usableSamples)` ($m[n] = \sqrt{x[n]^2 + y[n]^2 + z[n]^2}$), filters `rawMag`, and runs `welchPsdSingleAxis(filtMag, ...)`.
- **Mathematical Proof of $2f_0$ Rectification:**
  - Let $x(t) = A\sin(2\pi f_0 t)$, $y(t) = 0$, $z(t) = 0$ (after gravity removal).
  - In C++20 (`fuseAxes`), the Euclidean norm is full-wave rectification:
    $$m(t) = \sqrt{x(t)^2 + 0 + 0} = A|\sin(2\pi f_0 t)| = \frac{2A}{\pi} - \frac{4A}{\pi}\sum_{k=1}^{\infty} \frac{\cos(2\pi (2k f_0) t)}{4k^2 - 1}$$
  - The Fourier coefficient at the true fundamental frequency $f_0$ is **identically zero** ($0.0$). After `highPassFilter` removes the DC term $\frac{2A}{\pi}$, the dominant spectral component is the $k=1$ harmonic at **$2f_0$** with amplitude $\frac{4A}{3\pi} \approx 0.4244 A$.
  - **Verified Numerical Output ($f_0 = 0.6, 1.0, 2.0, 5.0\text{ Hz}$):**
    - Kotlin `psdMagnitude` (`psdX + psdY + psdZ`): Top peak at **`0.6008 Hz`, `1.0002 Hz`, `1.9998 Hz`, `5.0006 Hz`** (exact $f_0$).
    - C++20 `psdMagnitude` (`welchPsdSingleAxis` of $\sqrt{x^2+y^2+z^2}$): Top peak at **`1.1995 Hz`, `1.9998 Hz`, `3.9997 Hz`, `9.9993 Hz`** (**100% frequency doubling to $2f_0$**).
